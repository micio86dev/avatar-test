# LOCALE-QUALIFIED FORMAT (framework-catalog-it-translations, design D2a).
# Previously this file's entries were "ROLE_A:ROLE_B:COMP:FIELD" with no
# locale field — implicitly English, because no other locale existed. Once
# Italian translation lands (a locale dimension added to every leaf, design
# D1), a FAITHFUL translation of two byte-identical English sentences
# produces two byte-identical Italian sentences: Italian legitimately adds
# entries here, one per already-baselined EN duplicate whose pair gets
# translated — not a new violation, and not something to fix by rewording
# the Italian differently from the English (that would score the two
# locales differently on the exact indicator this file already excuses,
# which Constraint 1 of the IT-translations proposal forbids).
#
# THIS IS NOT A MUTE SWITCH — same doctrine, same both-direction enforcement,
# as scripts/framework-known-gaps.txt and scripts/framework-competency-gaps.txt:
#
#   * a cross-role duplicate found and NOT listed here        -> CI fails
#   * an entry listed here whose duplicate is no longer real  -> CI fails

# change's proposal, Question 2), PLUS — once authored — the faithful
# Italian translation of each. NEW pairs, and NEW divergences between what a
# faithful translation would produce, may add ZERO entries here. A new
# duplicate is a real defect in the new content and must be fixed by
# rewording, not exempted by editing this file.
#
